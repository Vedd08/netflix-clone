# Netflix Clone

This is a **Netflix Clone** built using **HTML** and **CSS**. It's a basic project aimed at replicating the look and feel of the Netflix homepage with responsive design for a better user experience.

## Features

- **Responsive Design:** The website adapts to different screen sizes, providing a great experience across desktops, tablets, and mobile devices.
- **Navigation Bar:** Includes a simple navigation bar with options like "Sign In" and "Language Selection".
- **Hero Section:** A large section at the top featuring a promotional message and an email input box.
- **Responsive Layout:** The layout changes based on screen size using CSS media queries.
- **Interactive FAQ Section:** Clicking on FAQ items reveals or hides answers.

## Technologies Used

- **HTML:** Used for structuring the webpage.
- **CSS:** Used for styling and layout design.
- **Google Fonts:** Used to enhance typography and improve the user experience.
  
## How to Run Locally

To run this project on your local machine, follow these steps:

1. Clone the repository:

    ```bash
    git clone https://github.com/your-username/netflix-clone.git
    ```

2. Navigate to the project directory:

    ```bash
    cd netflix-clone
    ```

3. Open the `index.html` file in your preferred browser:

    ```bash
    open index.html
    ```

    *(On Windows, you can double-click the file or open it in any browser.)*
